# 像素小猫桌面宠物 6717

这是一个参考示例造型、由程序重新绘制的原创像素小猫。它不包含原图水印，也不需要联网或安装第三方库。

内置六个原创像素形象：灰猫、柯基、饼干仓鼠、礼服柯基、黑猫和花开（FlowerBloom）。每次启动都会自动切换到下一个，六个形象循环展示；手动常驻模式与每小时模式共用同一轮换顺序。

## 启动

下载 ZIP 后必须先选择“全部解压缩”。进入解压后的 `pixel-pet-windows - 6717` 文件夹，再进入 `01-Start`，双击 `Start-Pixel-Pet.cmd`。不要在 ZIP 压缩包内部直接运行 CMD，否则 Windows 无法找到 `02-App` 中的程序文件。

目录已分成两个编号子文件夹：`01-Start` 只包含启动 CMD 和文字说明；`02-App` 保存主程序、图标以及每小时模式文件。

程序适用于 Windows 10/11，并在后台使用系统自带的 Windows PowerShell 与 WPF。

## 启动与灰猫桌面快捷方式

只需双击 `Start-Pixel-Pet.cmd`：第一次运行会使用第一只灰猫制作的图标，在桌面自动创建 `Pixel Pet` 快捷方式，同时立即启动宠物；后续双击桌面快捷方式或原 CMD 都只会运行宠物，不会重复创建快捷方式。每次运行仍会按照六种形象的顺序自动轮换。

桌面快捷方式通过 `wscript.exe` 调用隐藏启动器：PowerShell 控制台不会出现在屏幕或任务栏中；宠物窗口本身也不显示任务栏图标。退出请右键宠物并选择 `Exit`。

首次运行会把快捷方式所需文件和图标复制到 `%LOCALAPPDATA%\PixelCatPet\app`，所以之后即使移动或删除原来的解压文件夹，桌面快捷方式也可以继续使用。

如果 Windows 弹出安全提示，请确认文件来自你信任的位置后选择运行。脚本只会在 `%LOCALAPPDATA%\PixelCatPet\settings.json` 保存窗口位置、透明度和菜单设置。

## 互动

- 按住小猫拖动：把它放到喜欢的位置；之后它会沿这一高度散步。
- 普通显示和拖动时，透明窗口会缩到宠物本身大小，避免大面积透明窗口跨越屏幕边缘造成闪烁；松开后需要魔术或双击跳跃时才临时展开动画空间。
- 把宠物拖出任意屏幕边缘，直到这只宠物的双眼区域完全离开屏幕后再松开：随后播放紫色魔法环、彩色像素星光和中央闪光并切换下一只宠物。每个角色使用与自身画面对应的眼睛位置。
- 如果宠物已经越过屏幕边缘，但松开时眼睛仍有部分可见，它不会切换，而会轻微弹起、旋转滚动到屏幕正中央。
- 双击宠物：头顶会先出现一个更大的爱心，爱心快速放大并轻微回弹；预备动画结束后，宠物才放大到 2 倍冲向屏幕上边缘。撞击后旋转掉落并缩回原尺寸，最后滚回双击前的精确位置。动画期间会暂停散步，结束后自动恢复。
- 右键小猫：暂停/继续散步、切换置顶；在 `Opacity / 透明度` 中选择 100%、80%、60%、40% 或 20%，也可以让宠物回到右下角或退出。透明度会在下次启动时自动恢复。
- 小猫会随机停下、眨眼、摇尾巴，然后继续走动。

## 每小时出现 30 秒

进入 `02-App`，双击 `Enable-Hourly-Mode.cmd` 即可一键启用：小猫会在后台安静等待；每满一小时，并且屏幕处于亮屏和解锁状态时，它会出现 30 秒。如果到点时熄屏或锁屏，会等恢复使用电脑后再出现。

该模式只在本次登录会话中运行，不创建开机启动项，也不需要管理员权限；重启或注销电脑后自动停止。首次启用后约一小时出现，需要时可再次双击启用。

双击 `Disable-Hourly-Mode.cmd` 可立即关闭后台小猫。普通的 `Start-Pixel-Pet.cmd` 始终可用于手动启动常驻模式。

## 卸载

先从右键菜单退出，再删除整个文件夹即可。若也想删除位置记录，可删除 `%LOCALAPPDATA%\PixelCatPet` 文件夹。
