# Pixel Pet Windows · 6718

Windows 像素桌面宠物，内置六种形象，无需联网或安装第三方库。

## 下载与启动

点击页面绿色 **Code → Download ZIP**，全部解压后进入 `01-Start`，双击 `Start-Pixel-Pet.cmd`。

也可下载固定版本：[6718 ZIP](https://github.com/y99854-ui/pixel-pet-windows/archive/refs/tags/v6718.zip)。

## 6718 新增

- 拖到桌面下边缘松手，宠物立即趴下休息并暂停散步。
- 向上拖离边缘超过 40 像素，再拖回，切换为偷瞄；重复操作交替切换。
- 沿边缘横向拖动不会切换，拖回桌面其他位置恢复普通状态。
- 下边缘通常是任务栏上沿；左、右、上边缘仍保留原有换宠物和滚回中央行为。

详细使用方法见 [说明书](02-App/README.md)，本次变化见 [6718 更新说明](6718-更新说明.txt)。
