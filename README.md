# Pixel Pet Windows · 6719

Windows 像素桌面宠物，内置六种形象，无需联网或安装第三方库。

## 下载与启动

点击页面绿色 **Code → Download ZIP**，全部解压后进入 `01-Start`，双击 `Start-Pixel-Pet.cmd`。

也可下载固定版本：[6719 ZIP](https://github.com/y99854-ui/pixel-pet-windows/archive/refs/tags/v6719.zip)。

## 6718 新增

- 拖到桌面下边缘松手，宠物立即趴下休息并暂停散步。
- 向上拖离边缘超过 40 像素，再拖回，切换为偷瞄；重复操作交替切换。
- 沿边缘横向拖动不会切换，拖回桌面其他位置恢复普通状态。
- 下边缘通常是任务栏上沿；左、右、上边缘仍保留原有换宠物和滚回中央行为。

详细使用方法见 [说明书](02-App/README.md)，本次变化见 [6719 更新说明](6719-更新说明.txt)。
## 6718.1 稳定性修复

- 将底层窗口消息回调改为 C# 执行，避免在没有 PowerShell Runspace 的线程上运行脚本回调。
- 自测启用真实窗口消息回调，覆盖窗口显示、隐藏、关闭及六种宠物交互。
- 更新快捷方式安装标记，重新启动后自动更新已安装的程序。
- 本次修复针对已复现的回调异常；尚无日志能确认用户报告的“内存不能为 read”与它是同一原因。

## 6718.2 新增睡垫

下边缘休息与偷瞄时显示淡紫色像素睡垫，宠物脚爪落在垫面上，垫子底部贴边；拖离后恢复普通造型。


# 6719 更新说明

每只宠物使用独立颜色的睡垫，休息和偷瞄共用该角色的配色：

- 灰猫：天空蓝
- 柯基：薄荷绿
- 饼干仓鼠：奶油黄
- 礼服柯基：玫瑰粉
- 黑猫：薰衣草紫
- 花开：蜜桃橙

保留下边缘趴下、拖离再拖回切换休息/偷瞄及窗口回调稳定性修复。
